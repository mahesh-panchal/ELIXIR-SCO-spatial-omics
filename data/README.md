# Datasets

Each dataset is stored in its own subdirectory. The `fetch_data.sh`
script contains a description of the dataset and the code to download
the data. Run the script using Pixi or manually in a terminal.

Note: When adding a new dataset, add a fetch task to the `pixi.toml`.

## Available Datasets

- MERFISH_Mouse_Brain_ABCA
- SpatialGEP_Human_Glioblastoma
- SpatialHD_Mouse_Small_Intestine
- Visium_Mouse_Brain_Coronal
- XeniumIS_Mouse_Brain_TgCRND8
